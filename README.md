# Manual-Testing-Portfolio
Portfolio showcase for Manual Testing, Test Cases, Bug Reports, and API Testing.
## Skills
- **Manual Testing:** Requirement Analysis, Test Scenario / Test Case, Functional Testing, UI Testing, Web Testing, Bug Reporting, Retest / Confirmation Testing.
- **SQL:** Có khả năng sử dụng SELECT, JOIN, WHERE, GROUP BY, HAVING, ORDER BY để truy vấn và kiểm tra dữ liệu phục vụ quá trình Testing.
- **Nắm vững:** SDLC, STLC, Bug life cycle, Test Levels, Test Types.
- **Công cụ:** Redmine, Postman, Figma, Mindmup.
- **AI hỗ trợ Testing:** Sử dụng Claude/ChatGPT/Gemini để tham khảo khi phân tích Requirement, gợi ý Test Scenario và rà soát trường hợp kiểm thử, kết quả được kiểm tra lại trước khi sử dụng.
- **Hiểu rõ:** Quy trình phát triển phần mềm theo phương pháp Agile/Scrum.
